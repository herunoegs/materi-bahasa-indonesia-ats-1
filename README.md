# Materi Bahasa Indonesia ATS I

Aplikasi ini dibuat sebagai media pembelajaran Bahasa Indonesia untuk Asesmen Tengah Semester I Tahun Pelajaran 2026/2027.

## Fitur
- Ringkasan materi lengkap
- Latihan soal interaktif
- Mudah dibuka di browser
- Cocok untuk GitHub Pages

## Cara menjalankan
1. Buka file `index.html` langsung di browser, atau
2. Aktifkan GitHub Pages pada repository ini dan pilih branch `main`.

## Struktur file
- `index.html` — halaman utama
- `style.css` — tampilan desain
- `script.js` — latihan soal interaktif

## Catatan
Untuk menampilkan aplikasi secara online melalui GitHub, aktifkan fitur GitHub Pages di menu repository -> Settings -> Pages, lalu pilih:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/root`

Aplikasi akan tersedia di URL seperti:
https://username.github.io/nama-repository

Ganti `username` dan `nama-repository` sesuai akun GitHub dan nama repo Anda.
